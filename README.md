# see you

一个 Windows 桌面侧边便签，用来安排待办、记录完成事项和写每日复盘。离线使用，无需账号，数据保存在本机。

[下载 Windows EXE](dist/see%20you.exe?raw=true) · [重点优化记录](CHANGELOG.md) · [第三方依赖](THIRD_PARTY_NOTICES.md)

## 使用

双击 `dist/see you.exe`。程序默认收在屏幕侧边，标签上方为 `see`、下方为 `you`，点击展开。展开后可拖动顶部移动位置，靠近左右边缘会吸附；点击窗口外收起，也可以点击图钉保持展开。

| 分组 | 默认状态 | 行为 |
| --- | --- | --- |
| 立即做 | 展开 | 按列表顺序优先处理 |
| 以后做 | 收起 | 保存暂时不做的事项 |
| 明天做 | 收起 | 次日合并到立即做的末尾 |

点击分组标题或箭头展开、收起。点击各组的 `＋`，直接在组内输入；收起的分组会自动展开。第一行写要做的事，下面可补充内容。点击勾形按钮保存，叉形按钮取消；第一行按 Enter 保存，补充内容中按 Ctrl+Enter 保存。

长按任务整行约 0.3 秒即可拖拽，也可以按住后直接移动。拖到其他分组或同组任务的上、下方，看到插入线后松开。列表边缘支持自动滚动，收起的分组也可接收拖入的任务。

### 完成与跨天

- 勾选后，当天任务保留在原分组末尾，以淡色和划线显示；再次点击可取消完成。
- 到第二天，已完成任务只从待办隐藏，历史记录继续保留。
- 未完成任务跨天保留，不会清空。
- 明天做引用同一条任务，到期后合并一次，不生成副本。关闭数日再打开，也会处理已到期计划。

### 复盘与记录

复盘页只有当天的可编辑记录，没有额外标题、提示语或纯白文本框。默认将光标放在已有内容末尾，并滚动到底部；停止输入约半秒自动保存。

记录页按日期倒序合并展示完成任务和复盘，可以展开、收起。没有任务、只有复盘的日期也会显示；两者都没有的日期不显示。历史任务和复盘均可原位编辑、删除，任务还可恢复为待办。编辑历史任务不会改变原完成日期。

### 数据与备份

数据位于 `%LOCALAPPDATA%\SideNote`。目录名沿用早期名称，以兼容已有记录；移动或替换 EXE 不会删除数据。

程序使用 SQLite 保存任务、排序、完成时间、复盘和窗口位置。`backups` 保留最近 14 个有数据日期的 JSON 快照。顶部菜单支持手动导出和恢复，恢复前会保留当前数据副本。日期按电脑本地日期处理。

仓库不包含个人数据库、真实待办、复盘内容或本地备份；下面的图片使用示例数据。

## 构建

运行环境为 Windows 10/11 和 .NET Framework 4.8。应用是可在 64 位 Windows 上运行的 x86 进程，托管依赖与 SQLite 原生库嵌入单个 EXE。

开发使用 C#、WPF、Microsoft.Data.Sqlite、SQLitePCLRaw 和 Costura.Fody。安装 .NET 10 SDK 后，在仓库根目录运行：

```powershell
dotnet build src/SeeYou/SideNote.csproj -c Release -p:DebugType=None
```

输出位于 `src/SeeYou/bin/Release/net48/see you.exe`。也可以运行根目录的 `Build.ps1`，它会把产物复制到 `dist/see you.exe`；VS Code 的默认构建任务调用同一脚本。

```text
src/SeeYou/          应用源码、图标、项目文件和嵌入的 SQLite x86 库
dist/see you.exe     可直接运行的成品
docs/images/        使用示例数据生成的界面图片
Build.ps1           构建并更新 dist 的脚本
CHANGELOG.md        迭代中的重点改动
```

## 验证与资源占用

已进行 Release 编译、数据保存与重载、跨组和组内排序、当天完成项置底、跨天保留、历史任务及复盘编辑删除、分组折叠、窗口显隐和光标末尾位置检查。界面通过 WPF 渲染查看。鼠标拖拽的检查覆盖布局落点与排序逻辑，仍需在实际显示器环境中体验手感；没有做长时间压力测试。

资源方面采用 Windows 桌面界面，不内嵌浏览器运行时；保存使用短延时，日期切换使用定时事件，长按和滚动定时器只在交互期间运行。历史记录按日期分批加载。EXE 约 2.6 MB，文件大小不等于运行内存；目前不承诺达到 80 MB 的内存目标。
